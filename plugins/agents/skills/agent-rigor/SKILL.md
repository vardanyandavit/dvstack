# Agent rigor

When to deepen only. Stay cheap by default. Add cost when ambiguity or risk is high.

Use this skill to decide whether to escalate — not to build a harness or run a long bakeoff.

## Escalate when

1. **Restate first.** Ambiguous ask → have the agent restate the problem in plain language before editing.
2. **Demand evidence.** Mechanism, rationale, tradeoffs — the one failing request, not the whole log. Unsupported confidence is not enough.
3. **Escalate model or effort.** Stronger model and higher effort when the cheap pass already missed, or blast radius is high (money, auth, user data, irreversible).
4. **Time-box exploration.** When the design is genuinely open and the cost of picking wrong is high, run a short throwaway prototype. Do not default to long bakeoffs.

If the ask is clear and the risk is low, stay on agent-ops-bar. If the work needs contracts, tool gates, or recover loops, use harness-engineering.

## Not this skill

Session hygiene: agent-session. Quality bar: agent-ops-bar. The system around the agent: harness-engineering.
